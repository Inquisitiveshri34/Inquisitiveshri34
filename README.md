## ✦ Featured Projects

### 1. ClauseCheck — Procurement RAG Assistant

**September – October 2026**

> An evidence-grounded AI assistant for supplier contract analysis.

**Tech:** Python · ChromaDB · BM25 · Sentence-Transformers · Groq · Gemini · SQLite · FastAPI · Streamlit

- Co-built a RAG assistant (team of 2) processing **158 documents, 69 suppliers and 8K clause chunks**.
- Engineered clause-aware chunking and hybrid retrieval using vector search and BM25 with Reciprocal Rank Fusion.
- Implemented cross-encoder reranking and amendment expansion, achieving **93.5% Recall@5** across 31 evaluation questions.
- Integrated deterministic citation and figure verification, achieving **100% correct refusals** and 3.2% false refusals.
- Resolved 37 cross-module defects and contributed to a system with **375 passing tests**.

### 2. ChargeBackLens — Transaction Dispute Risk & Decision Engine

**August – September 2026**

> Turning transaction risk predictions into financially optimized decisions.

**Tech:** Python · NumPy · Pandas · Plotly · Scikit-learn · Streamlit

- Built a calibrated dispute-risk scoring system over **120K+ transactions**.
- Achieved **9.7× base-rate PR-AUC** and 16.2× lift in the top 1% of transactions.
- Developed a leakage-safe feature pipeline with temporal validation and benchmarked four scoring models.
- Deployed calibrated Logistic Regression with **0.00185 calibration error**.
- Designed a three-band Allow / Step-up / Review decision policy, achieving **₹11.99 lakh net savings**, equivalent to 39.1% of exposure.
- Captured 43.2% of disputes while reviewing only 5% of transaction volume.

### 3. DeliverIQ — Delivery Route Optimiser

**April – May 2026**

> An end-to-end machine learning system for delivery ETA prediction.

**Tech:** Python · NumPy · Pandas · Plotly · Scikit-learn · Streamlit

- Architected an ML delivery ETA prediction pipeline processing **250K+ delivery trips**.
- Integrated multi-source traffic, weather and road-network datasets.
- Engineered data quality workflows addressing missing values, invalid foreign keys, outliers and inconsistent timestamps.
- Optimised Random Forest regression using Scikit-learn Pipelines and GridSearchCV.
- Achieved **7.83-minute MAE**, representing a **55% improvement over baseline**.
- Deployed an interactive Streamlit dashboard with automated inference and model performance visualizations.
